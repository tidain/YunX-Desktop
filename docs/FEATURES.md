## 解析与下载

- **分享链接解析**：识别夸克 / UC / 迅雷 / 百度 / 139 / 123 / 115 / 光鸭 / 蓝奏云 / 蓝奏云优享版 的分享链接，自动匹配提取码（可直接粘贴带提取码的整段文本）；
  另支持 GitHub 仓库 / 账号 / 文件直链
- **中文口令解析**：粘贴「绝对有效 咐置松君杂货铺叩苓」这类**不是链接的中文口令**也能解析 ——
  先试迅雷口令接口，无结果再问星海口令服务换回 `pwdId` 并合成标准分享链接，后续提取码 / 登录 / 列表 / 取链全走既有链路
  （口令原文会发往第三方服务，失败日志只记长度与原因，不落口令本体）
- **高速下载**：Range 分片并发 + 断点续传 + 失败自动重试 + 全局限速（令牌桶）；弹性区按字节顺序分配，
  保证分片物理相邻、连接复用率稳定
- **分片级 SHA-256 校验**：分片写入时增量算摘要（不额外读盘），合并时逐片重算比对，
  内容不一致即拒绝保存损坏文件；另可开启「全量 SHA-256」（合并顺带算，见「诊断与日志」）
- **下载线程数**：按平台分别设置（网盘 10 个 + 视频平台 7 个 + 通用 HTTP / GitHub，最高 512），
  设置弹窗支持「一列 / 两列」切换，随时可调
- **任务并发控制**：限制同时下载的任务数（默认 1，前台任务吃满带宽，其余排队）
- **临时转存清理**：百度 / 迅雷取链后清理；夸克保留到下载完成或删除任务后清理
- **暂停 / 继续**：暂停时以磁盘分片实际大小为准回写进度，恢复后进度不跳变
- **任务持久化**：进度按时间节流落盘，重启后任务状态与进度可恢复

## P2P 下载（磁力 / BT 种子 / ed2k）

在网盘、视频、GitHub 之外的一条独立下载链路，统一交给 Gopeed 引擎多线程下载。

- **链接形态**：磁力链接（`magnet:`）/ `ed2k://` 电驴链接 / 本地 `.torrent` 种子文件 —— 添加任务时可直接粘贴链接，或用「选择种子文件」导入本机种子
- **BT Tracker 管理**：新增独立的 Tracker 服务器二级页集中维护 tracker 列表（增删 / 编辑），BT 任务会把列表下发到引擎；
  此前公网磁力 / 种子因拿不到 tracker 而一直卡在「解析中」，现已修复
- **DHT 开关**：下载引擎页可开关 BT 的 DHT（分布式哈希表），按网络环境取舍
- **peer 概览**：下载中的磁力 / 种子 / ed2k 任务显示「种子 N · 连接 M · 节点 K」，实时反映连接与做种情况
- **状态文案**：磁力 / 种子 / ed2k 解析阶段统一显示「正在解析…」

## GitHub 解析

GitHub 为代码托管平台（仓库 / 账号 / 文件直链），非网盘；其链接与网盘分享链接同入口解析。

- **链接识别**：识别仓库主页、账号（用户 / 组织）主页、仓库子路径（`tree` / `blob`）、`releases/latest`、
  发布资产直链与 `raw` 直链；可直接粘贴含 GitHub 链接的整段文本
- **浏览**：仓库文件树 / Releases / 账号（用户或组织）仓库列表；分页「加载更多」、显示 fork 来源、
  目录条目显示「最后提交时间」
- **README 渲染**：GFM Markdown（表格 / 代码 / 折叠 / 图片）；图片经自研加载器渲染（不使用 Coil），
  走 OkHttp 拉取 + Skia 解码，带内存缓存与加载中 / 失败占位，支持镜像前缀加速
- **下载**：GitHub 文件 / ZIP 加入现有下载任务，走镜像加速，失败可回退原始 GitHub 直链
- **镜像自动测速**：内置五个 gh-proxy 系镜像，下载前并发实测延迟与下载速度（256KB 分片），**按速度选最快**；
  设置页可查看每个镜像的 ping / 下载速度、手动刷新测速，也可固定某一个或填自定义前缀
- **Token（可选）**：Personal Access Token 仅用于提升 API 限额（未认证 60 次/小时，认证后 5000 次/小时）；
  经 AES-GCM 加密存储（桌面版密钥文件 `credential.key`）、输入框掩码显示、不写入日志；
  API 返回 401 时自动清除 Token 并提示

## 视频解析与预览

比网盘分享更轻的一条链路：粘贴作品链接即可拿到可播/可下载的媒体（不需要分享目录树）。

- **支持平台**：抖音 / 快手 / 微博 / 小红书 / AcFun（匿名可解析）；哔哩哔哩（登录后取高清）；
  Pixiv（登录后取全量，网页登录 + 手动填 Cookie）
- **解析内容**：标题 / 作者 / 封面 / 文案 / 发布时间 + 媒体列表（清晰度、大小、是否 HLS）
- **图集查看**：图片笔记以网格展示，点开可缩放（滚轮以鼠标为锚点）/ 拖拽 / 双击复位
- **在线预览播放器**：
  - **ffplay（推荐，真·边下边播）**：直接读 http(s) 直链、原生支持 HLS，不用先拼成本地文件；
    窗口用 `SetParent` 嵌进应用窗口，控制条画在视频区之外（播放 / 暂停、进度拖动、静音、全屏）；
    seek 走「重启进程 + `-ss`」，切换期间用最后一帧 + 半透明遮罩盖住黑屏
  - **内置 JavaFX（兜底）**：本机没有 FFmpeg 时自动使用；播放 / 暂停、进度拖动、0.5x~2x 倍速、静音、全屏；
    直链经本地回环代理注入 `Referer` / `User-Agent` / `Cookie`，防盗链平台也能播
  - 预览引擎可在「设置 → 引擎管理」选「自动（默认）/ FFplay / 内置 JavaFX」
- **视频引擎（FFmpeg）在线下载**：ffplay / ffmpeg 精简版（约 50–90MB）不随包发布；首次预览缺引擎时弹窗询问是否下载，
  选「暂不」继续用内置播放器。一键下载到应用私有目录（**不改系统环境变量 / PATH**），
  下载完成立即生效并自动用新引擎重新起播；「引擎管理」页可随时下载 / 更新 / 卸载，并显示当前引擎路径与来源
- **DASH 合轨优先 ffmpeg**：装了 FFmpeg 用 `-c copy` 无损快速合轨；没装则退回内置 Java 合轨，只提醒不阻塞本次下载
- **AcFun 边下边播**：m3u8 由自研 TS→fMP4 重封装器边下载边生成，不用等整包下载
- **B 站高清预览**：DASH 分轨没法直接喂播放器，解析时另取一份单文件直链仅供预览（下载仍走高清分轨）
- **下载形态**：单文件 MP4、HLS（分片下载后合并；装了 FFmpeg 时自动 `-c copy` 转封装为 MP4 并回写真实大小）、
  B站 DASH 高清（自研分片合轨，优先 AVC）、微博/抖音 Live Photo（合成单张 JPEG，也可选存静图或存成视频）、图集批量
- **小红书去水印**：图集换成原图 CDN 地址；原图不存在时自动回退平台地址并在结果页提示

## 浏览器插件

仓库 `browser-extension/` 内的 Chrome / Edge 扩展「云析下载助手」（Manifest V3），把浏览器下载接管到云析。

- **嗅探资源**：`webRequest` 只读观察响应头 + 页面 DOM 扫描，列出当前网页里可下载的媒体与文件
  （视频 / 音频 / 压缩包 / 安装包 / 文档等），按图片 / 视频 / 音频 / 文档 / 压缩包 / 程序 / 字体分类，
  图片与视频支持卡片预览
- **接管浏览器下载**：`downloads.onCreated` 自动接管 —— 取消浏览器下载并抹掉记录（`byExtensionId` 防循环），
  改由云析下载；云析弹窗询问保存目录与线程数（最高 512，超过 32 需二次确认）
- **归还浏览器下载**：在云析弹窗点「归还浏览器下载」后重新发起浏览器原生下载，并对该**页面网站
  （根域名 eTLD+1 及其以下子域名）**写入 **5 分钟冷却**，冷却期内不再接管；冷却按「发起下载的页面域名」锚定，
  与资源是否来自第三方 CDN 无关
- **冷却倒计时与手动恢复**：冷却期内打开插件弹窗显示「还有 X 分 YY 秒自动重新开始捕获」倒计时，
  可点「立即重新开始」单独解除**当前网站**的冷却、手动恢复捕获
- **视频平台卡片**：B 站视频页提供「清晰度 + 下载方式」下拉；抖音 / 微博 / AcFun 视频页提供
  「交给云析下载」按钮，经 `/video` 静默通道提交，由云析解析链接（含短链展开）后按最高可用档入队
- **手动下载**：插件资源列表、右键链接 / 视频 / 图片均可「用云析下载…」
- **开关**：总开关（关闭后不嗅探、不接管）、接管浏览器下载开关、嗅探页面资源开关
- **安全**：扩展与云析通过本机回环 HTTP（`127.0.0.1:37021-37030`，随机 token）通信，网页脚本无法伪造请求；
  云析没运行时探测不到端口，扩展完全不干预浏览器下载

## 任务管理

- 暂停 / 继续 / 删除
- 打开文件 / 在资源管理器中显示（`explorer /select` 直接选中目标文件）
- 复制直链 / 复制分享链接
- 下载完成项一键定位「文件夹」
- **失败任务置顶**：失败任务自动排到列表最前（含文件夹分组内部），不会被其它任务淹没

## 通知与保活

- **Windows 通知中心进度**：下载进度显示为 toast 进度条，多任务自动聚合成一条，附带实时速度与完成度
  - 同一条通知**原地刷新**，不会每次刷新都弹横幅或响铃
  - **送达自检**：发送后核对 Windows 为应用维护的 `LastNotificationAddedTime`，若系统静默丢弃了通知，
    会自动创建带 AppUserModelID 的开始菜单快捷方式兜底（位于
    `%APPDATA%\Microsoft\Windows\Start Menu\Programs\`）；正常情况下不会改动开始菜单
  - 受系统通知设置影响，**不保证 100% 送达**
- **完成通知**：全部任务下载完成时额外提示一条
- **阻止电脑休眠**：下载期间通过 `SetThreadExecutionState` 阻止系统睡眠，任务结束自动恢复

## 登录与账号

- **内嵌浏览器登录（推荐）**：夸克 / UC / 百度 / 139 在应用内打开真实 Chromium 页面（JCEF 132），
  登录后自动检测并保存 Cookie，全程无感
- **一键导入本机浏览器 Cookie**：扫描 Chrome / Edge / Firefox / 360 / QQ 等，用 Windows DPAPI 解密导入
  （Chrome / Edge 较新版本受「应用绑定加密」限制可能读不到，Firefox / 360 等始终可用）
- **手动粘贴 Cookie**：兜底方式
- **迅雷**：账号密码 + 短信验证（验证页由系统浏览器承载）；**123 云盘**：账号密码换 JWT
- **登出彻底清除 Cookie**：通过 CEF 的 `delete` 标志清除该平台全部 Cookie，避免残留
- **认证备份**：用户口令派生密钥（PBKDF2）+ AES-GCM 加密 Cookie / JWT，导出 `.yunx` 备份文件，可跨设备恢复（含网盘与视频解析平台的全部账号，保留主账号 / 备注）

## Windows 系统集成

- **系统托盘**：左键恢复主窗口（含从任务栏最小化状态恢复）；右键为 Win32 原生菜单，中文显示正常
- **菜单跟随系统配色**：深色 / 浅色切换后菜单随之变化（内置原生桥接层 `darkmode.dll`）
- **关闭行为可选**：每次询问 / 直接退出 / 最小化到系统托盘
- **原生文件对话框**：下载目录选择、备份导入 / 导出均为资源管理器同款样式（Vista+ COM `IFileDialog`）
- **下载目录解析**：经 Known Folder API 读取系统「下载」位置，支持用户重定向过的路径
- **剪贴板分享链接检测**：主窗口不在前台时检测剪贴板，发现分享链接在右下角弹出提示卡片，
  点击即打开解析（可在设置中关闭）
- **启动与关闭过渡**：启动闪屏 + 主窗口内容就绪后渐入；关闭时先淡出再销毁，避免白屏闪烁

## 界面与体验

- 深色模式 + 自定义种子色（Monet 风格动态取色）
- 链接收藏；解析链接历史（1 小时去重，支持搜索 / 复用提取码 / 删除 / 清空）
- 弹窗统一为窗口内覆盖层渲染，不创建原生窗口，避免阻塞 UI 线程与动画卡顿
- **主窗口启动位置**（设置 → 主窗口启动位置）：可指定窗口首次出现的位置；「设置位置」进入全屏遮罩，
  把窗口拖到屏幕任意处后一键记录，下次启动即按该位置摆放
- **新建任务名称实时识别**：添加下载时「名称」输入框随粘贴的链接实时重算占位名称，确认前即可看清将保存的文件名
- **下载列表滚动条常驻**：下载列表右侧显示常驻滚动条，任务多时一眼可见当前位置
- 渲染后端可选：默认 `OPENGL`（动画流畅且文字清晰），
  可用环境变量 `YUNXPC_RENDER_API=SOFTWARE|DIRECT3D|OPENGL` 切换
- 更新检测：**启动时自动检查**（网络失败 / 已是最新 / 已选「不再提示该版本」的版本静默不打扰，
  「不再提示」按版本记住、不是全局关闭），设置页也可手动检查；
  读取 GitHub Releases 并提示新版本，可自行选择安装包或便携包，更新说明以 Markdown 渲染；
  发布说明写了「强制更新 / 最低强制更新版本」时按规则拦截（不可关闭、无「稍后」）；
  预览版（version.txt 标记）在关于页版本号旁显示黄色 **Beta** 标记
- **网络设置**：GitHub 下载镜像（默认「自动」—— 实测选最快；可固定内置五选一或填自定义前缀）、
  网络代理（不使用代理 / 使用系统代理 / 手动配置，默认直连，启动与设置变更时装配）
- **实验性功能**（设置 → 实验性功能二级页）：集中管理高风险 / 可调下载参数，支持一键重置为默认值 ——
  HTTP/2 开关（默认关闭，仅使用 HTTP/1.1；开启后允许 ALPN 协商 h2）、
  下载读缓冲大小（默认 64KB；档位 16/32/64/128/256/512/1024 KB，也可直接输入 **16–4096 KB** 内任意值）、
  慢连接抢占（默认开启，默认 12KB/s · 15 秒；阈值 **4–10240 KB/s**、判定时长 **5–600 秒**，均支持档位选择或直接输入）、
  单线程直写（实验性，默认关闭；线程数为 1 时不写缓存分片，直接写目标目录的 `.yunx-*.part`，完成后改名）、
  多线程直写（实验性，默认关闭；线程数 > 1 时预分配单个 `.part`，各线程按字节偏移并行写，`.plan` / `.done` 记录进度，恢复时逐片校验）、
  主页快捷方式（默认关闭，开启后在解析页以横向快捷方式展示收藏，点击直达解析）。
  ★ 直写仅对「内置下载器」生效（Gopeed 引擎本身直接落盘）；临时文件会出现在下载保存目录，暂停/失败后保留以便续传；
  目标盘为移动硬盘/网络盘时断开会导致该任务无法续传，开关变更不会改变已开始任务已选择的模式。
  ★ 每个数值项都分「**合理范围**」与「**硬上限**」两档：读缓冲合理 16–1024 KB、阈值合理 4–1024 KB/s、时长合理 5–120 秒；
  超出合理范围时会弹确认框提醒（仍可启用，但内存占用/速度/稳定性等风险与后果由使用者自行承担，开发者不对此负责）

## 诊断与日志

- **导出日志**（设置 → 导出日志）：导出运行日志文本（可「在文件夹中显示」或「保存到下载目录」），含系统 / Java 版本头部信息
- **诊断模式**（设置 → 关于云析 → 长按 → 开发调试 → 诊断模式，默认关闭）：开启后把
  `db / crypto / download / webview / network / operation` 六个模块的详细日志**按模块分文件**写进
  `<数据目录>/diagnostic_logs`，跨重启保留；带全局限流（300 行/秒）与自动轮转（单文件 2MB、每模块 5 份、总量上限 10MB），
  **关闭时一行都不写**（调用点零开销）。敏感信息经过脱敏：URL 走 `LogRedactor`、请求体/响应体只在
  非 200/206 或抛异常时记录（各截 1.5KB）、凭证只记用途与长度不记内容
- **导出诊断日志（zip）**：先 flush 再打包成 `yunx_diagnostic_logs_<时间戳>.zip`，便于把复现步骤对应的完整日志一次带走
- **下载调试**（设置 → 关于云析 → 长按 → 开发调试 → 下载调试，默认关闭）：按**任务**记录事件流
  （入队 / 断点失效 / 分片规划 / 抢占慢连接与结果 / 网络变化 / 合并与校验 / 完成 / 失败 / 暂停 / 删除 …）。
  开启后**右键下载任务 → 调试信息**可进调试页：任务卡 + 全局资源（在飞配额 / 活跃任务 / 线程池 / 堆内存）+
  线程表（每个在飞分片由哪个 worker 负责、区间、已收、瞬时速度、抢占次数，可「重连」强制换连接）+
  实时日志跟随（等宽字体，可复制快照 / 导出完整下载日志）。数据为拉取式、只活在内存，**不打开调试页时零额外开销**；
  **关闭开关会清空全部调试日志**（有二次确认）
- **全量 SHA-256**（仅在「下载调试」开启时可见，默认关闭）：保存文件时顺带算出整文件摘要写进调试日志；
  与合并复用同一遍 IO，不额外读盘，只多一点 CPU

## 数据与备份

- **储存目录**（设置 → 储存目录，二级页）：集中管理三处位置，都可改且**重启后生效**，切换时自动搬迁旧数据
  - **下载保存目录**：下载完成后的落盘位置（默认系统「下载」；内置下载器与 Gopeed 引擎共用）
  - **下载缓存目录**：分片 / 合并临时文件 / 内嵌浏览器数据（含网页登录态）；预设「默认（用户目录）/
    应用所在目录（便携）/ 自定义」
  - **数据库位置**：`yunx.db` 与 `credential.key`（库内凭证用它加密，必须同处一地）；
    目标目录已存在 `yunx.db` 时拒绝切换
  - **数据库加密等级**（立即生效，无需重启）：控制凭证主密钥怎么保护。三档都只重新包裹 32 字节主密钥，
    不动库内数据：

    | 档位 | 库文件 | 凭证列 | 密钥 `credential.key` |
    | --- | --- | --- | --- |
    | **宽松** | 明文 SQLite | AES-256-GCM | 明文（换机器 / 便携版用这档） |
    | **普通**（默认） | 明文 SQLite | AES-256-GCM | 本机派生密钥包裹（PBKDF2 21 万次；绑定本机） |
    | **较为严格** | 明文 SQLite | AES-256-GCM | Windows DPAPI 保护（绑定当前 Windows 用户） |
    | 严格 | 整体加密 | — | SQLCipher + DPAPI（**暂未支持**） |

    ⚠ 数据库位置改到「应用所在目录 / 自定义」时，界面会提示：若要当便携版带到别的电脑，
    加密等级需切回「宽松」—— 本机派生密钥与 DPAPI 都是绑定本机的，换机后无法解密（凭证需重新登录）。
- **认证备份**：用户口令派生密钥（PBKDF2）+ AES-GCM 加密 Cookie / JWT，导出 `.yunx` 备份文件，可跨设备恢复（含网盘与视频解析平台的全部账号，保留主账号 / 备注）

数据目录说明见 [使用说明](USAGE.md)。
