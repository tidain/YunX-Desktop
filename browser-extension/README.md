# 云析下载助手（浏览器扩展）

嗅探网页资源、接管浏览器下载并交给 **云析（YunX-Desktop）** 多线程下载的 Chrome / Edge 扩展（Manifest V3）。

## 功能

- **嗅探资源**：通过 `webRequest` 只读观察响应头 + 页面 DOM 扫描，列出当前网页里可下载的媒体与文件（视频 / 音频 / 压缩包 / 安装包 / 文档等）。
- **接管浏览器下载**：浏览器开始下载时自动接管 —— 取消浏览器下载并抹掉记录，改由云析下载。
- **弹窗询问**：接管后由云析弹出询问窗，选择「保存到哪里」与「用多少线程」（最高 512；**超过 32 需二次确认**）。
- **归还浏览器下载**：在云析弹窗点「归还浏览器下载」后，扩展会重新发起浏览器下载，并对该**页面网站（根域名 eTLD+1 及其以下所有子域名）**写入 **5 分钟冷却**，冷却期内不再接管该网站的下载请求（按「发起下载的页面域名」锚定，与资源是否来自第三方 CDN 无关）。冷却期内重新打开插件弹窗会显示「还有 X 分 Y 秒自动重新开始捕获」的倒计时，并可点「立即重新开始」单独解除该网站的冷却、手动恢复捕获。

## 工作原理

扩展与云析通过**本机回环 HTTP**通信（IDM 同款思路，无需注册原生消息宿主）：

```
扩展 ──GET /ping──▶ 127.0.0.1:37021-37030   （探测云析，取本次进程的随机 token）
扩展 ──POST /hook──▶ 云析                   （提交接管请求，挂起等待用户在弹窗里决定）
云析 ──决策 JSON──▶ 扩展                    （accept 交给云析 / cancel 取消 / return 归还浏览器）
```

- 云析只监听 `127.0.0.1`，且校验随机 token，网页脚本无法伪造请求。
- **云析没运行时探测不到端口，扩展完全不干预浏览器下载**，行为与未安装插件一致。

## 安装

1. 启动云析（桌面版），确认其正常运行。
2. Chrome / Edge 地址栏打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
3. 打开右上角 **开发者模式**。
4. 点 **加载已解压的扩展程序**，选择本 `browser-extension` 文件夹。
5. 浏览器工具栏出现云析图标即安装成功；点击图标可查看连接状态与当前页面资源。

## 使用

- **自动**：任意网页触发下载时，浏览器下载会被取消，云析弹出询问窗 → 选目录 / 线程数 → 下载。
- **手动**：点击工具栏图标，在资源列表里对某项点「云析下载」；或右键链接 / 视频 / 图片，选择「用云析下载…」。
- **归还**：在云析弹窗点「归还浏览器下载」；该根域名 5 分钟内不再被接管。冷却期内点插件图标可看到剩余时间，并点「立即重新开始」提前恢复捕获。

## 开关

点击工具栏图标可开关：

| 开关 | 说明 |
| --- | --- |
| 启用插件 | 总开关，关闭后不嗅探、不接管 |
| 接管浏览器下载 | 关闭后只嗅探，不接管浏览器下载 |
| 嗅探页面资源 | 关闭后不再记录资源列表 |

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | MV3 清单 |
| `background.js` | 服务后台：端口探测、下载接管、资源嗅探、冷却与归还 |
| `content.js` | 页面脚本：按需收集 DOM 资源 |
| `popup.html/.css/.js` | 工具栏弹窗：连接状态、开关、资源列表 |
| `_locales/zh_CN/messages.json` | 本地化文案（`default_locale: zh_CN`），供商店识别语言与显示名称/简介 |
| `icons/` | 图标 |

## 隐私

所有数据仅在本机浏览器与云析之间传递，**不上传任何数据**。
