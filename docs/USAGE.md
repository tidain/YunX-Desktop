# 使用说明

> 概览见 [README](../README.md) ｜ 完整功能见 [功能清单](FEATURES.md)

## 快速上手

1. 在「网盘」页登录需要使用的网盘账号（推荐内嵌浏览器登录）
2. 在「解析」页粘贴分享链接（可带提取码，支持从剪贴板一键粘贴）
3. 浏览分享内容，点击文件加入下载
4. 在「下载」页查看进度，支持暂停 / 继续 / 删除 / 打开；进度同步显示在 Windows 通知中心

## 登录方式

| 方式 | 适用 | 说明 |
| --- | --- | --- |
| 内嵌浏览器登录（推荐） | 夸克 / UC / 百度 / 139 | 应用内打开真实 Chromium 页面，登录后自动检测并保存 Cookie |
| 一键导入本机浏览器 | 同上 | 扫描本机已装浏览器，用 Windows DPAPI 解密并导入其 Cookie（Chrome / Edge 较新版本受「应用绑定加密」限制可能读不到） |
| 手动粘贴 Cookie | 同上 | 兜底方式 |
| 账号密码 | 迅雷 / 123 | 迅雷为账号密码 + 短信验证（验证页由系统浏览器承载）；123 为账号密码换 JWT |

退出登录时会通过 CEF 的 `delete` 标志清除该平台的全部 Cookie。

## GitHub

GitHub 为代码托管平台，链接（仓库 / 账号 / 文件直链）在「解析」页粘贴即可识别、浏览与下载，README 以 GFM Markdown 渲染。

在「网盘」页底部的 **GitHub** 卡片可配置 **Personal Access Token**（可选）：仅用于提升 GitHub API 限额
（未认证 60 次/小时，认证后 5000 次/小时），经 AES-GCM 加密存储、输入框掩码显示；已配置后点击卡片可浏览当前 Token 账号的仓库。

**GitHub 下载镜像**与 **网络代理**在设置页配置。镜像默认「**自动**」：内置五个 gh-proxy 系镜像，
下载前并发实测延迟与下载速度，按速度选最快（延迟最低 ≠ 吞吐最大，所以不按 ping 选）；
设置页里能看到每个镜像的 ping 与下载速度、可随时「刷新测速」，也能固定某一个预选或填自定义前缀 ——
应用内所有 GitHub 下载（更新包、视频引擎、Gopeed 内核、README 图片代理）统一使用当前生效的镜像。
代理有三种模式 —— **不使用代理（直连，默认）**、**使用系统代理**（读取 Windows 系统代理设置，
会显示实际解析结果）、**手动配置代理**（自行填写主机与端口，端口默认 7890）。
暂不支持 PAC 自动配置脚本，检测到 PAC 时按直连处理并在日志中说明。

## 视频引擎（FFmpeg）

在线预览（边下边播）与 B 站 DASH 合轨都依赖 FFmpeg 套件，但它**不随安装包发布**（精简版约 50–90MB）。

- **来源**：优先用设置 → 「引擎管理」里下载到**应用私有目录**的副本，其次用本机已装（PATH / 常见安装目录）的 FFmpeg；
- **首次预览**：设为「自动」且本机没有引擎时，会弹窗问一次是否下载 —— 选「下载引擎」即后台下载，
  下完**当前这次预览会自动切到 ffplay 重新起播**；选「暂不」则继续用内置 JavaFX 播放器；
- **引擎管理页**（设置 → 引擎管理）：展示当前引擎路径与来源，可下载 / 更新 / 卸载（只删私有副本，不动系统里装的）；
- **合轨**：装了 FFmpeg 时 DASH 分轨用 `-c copy` 无损合轨，没装则退回内置 Java 合轨，只提醒不阻塞下载。

## 浏览器插件（Chrome / Edge）

仓库 `browser-extension/` 是配套扩展「云析下载助手」（Manifest V3），用于把浏览器下载接管到云析。

1. 启动云析（桌面版），确认其正常运行；
2. 浏览器地址栏打开 `chrome://extensions`（Edge 为 `edge://extensions`），打开右上角 **开发者模式**；
3. 点 **加载已解压的扩展程序**，选择 `browser-extension` 文件夹；
4. 工具栏出现云析图标即安装成功，点击图标可看连接状态与当前页面资源。

- **自动**：任意网页触发下载时，浏览器下载被取消，云析弹出询问窗 → 选目录 / 线程数 → 下载；
- **手动**：点工具栏图标，在资源列表里对某项点「云析下载」；或右键链接 / 视频 / 图片选「用云析下载…」；
- **归还**：在云析弹窗点「归还浏览器下载」；该页面网站 5 分钟内不再被接管。冷却期内点插件图标可看到
  「还有 X 分 YY 秒」倒计时，并可点「立即重新开始」提前恢复该网站的捕获；
- **开关**（点工具栏图标）：启用插件 / 接管浏览器下载 / 嗅探页面资源。

> 云析没在运行时扩展探测不到本地桥，**完全不干预浏览器下载**，行为与未安装插件一致。

## 设置项

| 分组 | 设置项 |
| --- | --- |
| 下载 | 下载线程数（按平台：网盘 / 视频平台 / 通用 HTTP / GitHub，最高 512；弹窗可切换一列或两列）、下载保存目录、最大同时下载任务数、下载速度限制、下载失败重试次数 |
| 系统 | 下载时阻止电脑休眠、通知中心下载进度、剪贴板分享链接检测、关闭主窗口时的行为 |
| 网络 | GitHub Token（提升 API 限额）、GitHub 下载镜像（自动选最快 / 固定预选 / 自定义前缀）、网络代理（不使用代理 / 使用系统代理 / 手动配置） |
| 引擎管理 | 下载引擎（Gopeed 内核）、视频预览引擎（FFmpeg 精简版）—— 下载 / 更新 / 卸载、引擎状态与路径、预览内核选择（自动 / FFplay / 内置 JavaFX） |
| 实验性功能 | HTTP/2 开关（默认关闭）、下载读缓冲大小（默认 64KB）、慢连接抢占（默认开启，阈值 12KB/s、判定 15 秒）、主页快捷方式（默认关闭）；支持一键重置为默认值 |
| 外观与更新 | 深色 / 浅色模式与种子色、检查更新 |

## 数据目录

| 路径 | 内容 |
| --- | --- |
| `%USERPROFILE%\.yunx-desktop\` | 应用数据根目录（可用环境变量 `YUNX_DESKTOP_DATA_DIR` 覆盖） |
| `%USERPROFILE%\.yunx-desktop\yunx.db` | 任务与凭证库（SQLite；位置可在「设置 → 储存目录」改） |
| `%USERPROFILE%\.yunx-desktop\credential.key` | 凭证加密密钥（AES-256-GCM；跟着数据库目录走） |
| `%USERPROFILE%\.yunx-desktop\cache\download_tmp\` | 下载分片临时目录（缓存目录可在「设置 → 储存目录」改） |
| `%USERPROFILE%\.yunx-desktop\files\yunx-desktop.log` | 运行日志（设置页可导出） |
| 注册表 `HKEY_CURRENT_USER\Software\JavaSoft\Prefs\yunx` | 偏好设置 |

> 旧版本使用的 `%USERPROFILE%\.yunx-pc\` 会在首次启动时**自动整体迁移**为 `.yunx-desktop`
> （登录态、下载任务、分片一并保留），无需手动处理。

### 储存目录（设置 → 储存目录）

三块内容都可在应用内更改，改动**重启后生效**，切换时会把旧位置的数据自动搬到新位置：

- **下载保存目录**：下载完成后文件的落盘位置（默认：系统「下载」文件夹）；内置下载器与 Gopeed 引擎共用。
- **下载缓存目录**：下载分片、合并临时文件与内嵌浏览器数据（含网页版登录态）；预设三档 ——
  默认（用户目录）/ 应用所在目录（便携）/ 自定义。内嵌浏览器的 ~200MB 解包文件不搬，会在启动时自动重建。
- **数据库位置**：`yunx.db` 与 `credential.key`（**必须同处一地** —— 库内凭证用它加密，分开会全部解不开）；
  预设同上三档。目标目录已存在 `yunx.db` 时会拒绝切换，避免两套数据混在一起。
- **数据库加密等级**（**立即生效，不需要重启**）：控制凭证主密钥怎么保护 ——

  | 档位 | 凭证主密钥 | 适用场景 |
  | --- | --- | --- |
  | 宽松 | 明文存放在 `credential.key` | **便携版 / 需要换机器**（唯一能跨机器的档位） |
  | 普通（默认） | 本机派生密钥包裹（PBKDF2，绑定本机） | 固定在一台机器上使用 |
  | 较为严格 | Windows DPAPI 保护（绑定当前 Windows 用户） | 同一台机器、希望密钥不被别的用户读取 |
  | 严格 | 整库加密（SQLCipher）+ DPAPI | **暂未支持** |

  > 三档都只保护**密钥**：库里的账号凭证始终是 AES-256-GCM 密文，但任务文件名 / URL / 保存路径等元数据
  > 在三种档位下都是明文。改档只重新包裹 32 字节主密钥、不动库内数据，秒级完成。
  >
  > ⚠ 「普通 / 较为严格」绑定当前机器（或 Windows 用户）：把数据拷到别的电脑、重装系统、换用户后
  > **凭证将无法解密**（表现为网盘账号全部未登录，需重新登录）。因此把数据库位置改到「应用所在目录
  > （便携）」时，界面会提示需要把加密等级切回「宽松」。

## 托盘与窗口

- **左键**托盘图标：恢复主窗口（包含从任务栏最小化状态恢复）
- **右键**托盘图标：原生菜单 —— 「显示主窗口」/「退出」
- 关闭主窗口时的行为可在设置中选择：每次询问 / 直接退出 / 最小化到系统托盘（下载继续）
